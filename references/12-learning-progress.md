# 学习进度、费曼闭环与个性化复习

## 1. 计划由学习者设定

先让学习者选目标（理解108课核心结构、会独立标注、会做点时复盘等）、每日/每周时间、每次时长、截止日和已有基础。把目标拆成可观察能力：概念解释、时序确认、图形迁移、备选划分、风险和反例。排课留出练习与间隔复测；不要以阅读篇数、学习时长或主观“精通”作结业证明。

## 2. 每课费曼循环

1. 闭卷用自己的话解释一个概念，并画出或描述逐根走势。
2. 记录学习者答案，再让其指出必要条件、可确认时点、失效情形和一种替代解释。
3. 教师只针对缺口简短重教，给一个不同标的/周期的例子。
4. 学习者纠错并完成迁移题；答案核对原典课程和当前明确声明的标注口径。
5. 用同一 rubric 评分，安排次日/三日/七日延迟复测；若错误反复出现，回退前置概念。

## 3. 本地学习记录入口

`scripts/learning_tracker.py` 使用本地 JSONL 文件，不上传或自动同步：

```powershell
python scripts/learning_tracker.py --file learner-progress.jsonl --learner-id learner-local --lesson 05-fractal --scores 2,3,1,2 --note "把pivot日说成信号日"
```

四维 rubric 依次为概念准确、解释清晰、例子迁移、错误自纠，每项0–4分：0=缺失或相反；1=重大误解；2=部分正确但缺关键约束；3=基本正确但需提示；4=独立、精确并能处理反例。记录只用化名；不要保存姓名、账户、联系方式或证券持仓。学习者可随时要求删除本地文件。

建议机制只按最近记录给下一步学习方向和复测间隔，不将分数解释为获利能力。≥3分也必须通过新周期迁移和延迟复测，才可判定概念暂时掌握。建议由学习者确认后纳入其计划，错误分数需可人工更正。

## 4. 真实学习者评估协议

小规模课程可用匿名前测/后测、新标的迁移题、延迟一周复测和学习者访谈评估。预先写明题目、rubric、评分者一致性、退出权、数据保留期和失败结果；至少双人盲评一部分答案，公开样本量与失访。避免把教师提示后的即时正确率当独立掌握或实盘投资能力。本版仅有工具/合成案例检查，尚无真实学习者测试或教学效果证据。
