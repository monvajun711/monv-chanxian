# 缠论学习框架：原典概念与审慎应用

本文件提供教学目录，不替代原文。定义以《教你炒股票》对应课程及其他原文为准；后人图解、公式和软件实现必须注明各自口径。

## 学习路径

1. **投资与操作观**：操作程序、当下分类、走势不可预测与可分类、交易节奏、资金管理、风险回避。阅读原典第1–17课以及第19、26、30–32、41、46、51、63、68、80、84、86、95–108课（课名/编号请回到原始目录逐条确认）。
2. **K线与形态**：K线包含关系处理、顶底分型、笔的定义及不同划分口径。练习每一步标出当时可确认的时间，禁止把未完成分型提前确认为信号。
3. **线段与走势类型**：特征序列、线段划分、走势类型的分类和级别。对存在多种合理划分处保留备选版本，不靠未来K线回填过去判断。
4. **中枢与递归**：走势中枢、延伸/扩张、走势类型连接、级别递归、自同构性。记录每个中枢上下界、构造它的次级走势和确认时间。
5. **动力学和交易点**：趋势/盘整背驰、MACD辅助、区间套、第一/二/三类买卖点、小转大。逐一写出必要前提、确认条件、失效条件及可执行时点。
6. **完整决策**：同级别分解、多义性、组合级别、仓位和交易成本，形成“观察—条件—执行/不执行—退出—复盘”的流程。

## 概念解释时的模板

每个概念依次说明：

1. 原文定义（课程号、发布日期和来源链接）。
2. 结构图或简短价格序列示例，标明时间顺序。
3. 最低成立条件和常见误用。
4. 另一种可能的划分/解释，以及为什么现在无法排除。
5. 该概念不意味着什么：尤其不等于确定预测、必然获利或风险消失。
6. 一道练习题及判定依据。

## 口径冲突处理

缠论社区和软件可能采用不同的包含处理、笔/线段确认条件、分型过滤、同级别分解和中枢定义。不要拼接成一个无来源的“正宗算法”。每次分析开头声明口径版本，并对关键划分做敏感性分析；若两种合理口径导出相反结论，应报告分歧而不是隐藏它。

## 投资思想与现代实践的连接

把缠论用于描述价格路径、构造状态分类和提出交易假设；再以独立的资产配置、基本面、估值、流动性、风险预算和纪律检验。价格走势结构本身不能说明公司价值、基金质量、债务偿付能力或适合某位用户的仓位。
