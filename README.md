# 魔女缠线｜缠中说禅学习与 A 股研究 Skill

面向学习者与研究者的 Codex Skill：系统学习缠中说禅理论、按决策时点复盘、研究 A 股/基金/债券，并生成可追溯的研究报告。

## 能力

- 费曼式课程：自定学习计划，闭卷解释、纠错、迁移练习与复习建议。
- 历史复盘：冻结当时可得信息，区分结构发生时间与确认时间。
- 市场研究：优先核对交易所、监管、上市公司和基金管理人等一手来源。
- 授权数据接入：支持本地 CSV、OHLCV/复权字段审计，以及明确口径的候选结构标注。
- 报告工作流：简明或全量研究报告、证据来源、情景风险、PDF 样例和本地校验工具。
- 知识目录：1,139 条公开文章元数据与 108 课编号索引，注明尚未逐篇蒸馏的范围。

## 使用

将本仓库作为 Skill 加载，或将整个仓库目录复制到 Codex 的 skills 目录。入口见 [SKILL.md](SKILL.md)，安装与使用说明见 [skillhub-listing.md](skillhub-listing.md)。

本地回归测试：

```bash
python -m unittest discover -s tests -v
```

## 数据与研究边界

当前行情入口要求用户提供获授权 CSV 或自行配置数据接口；本仓库不附带实时行情源、市场数据许可或 API 密钥。自动结构标注是指定定义口径下的候选结果，不能直接当作买卖信号。归档目录是元数据索引，不代表 1,139 篇正文已全部阅读和互证。Skill 的评分反映流程与工具成熟度，不代表理论有效性或投资表现。
